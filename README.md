# Companion Memory

本地、隐私优先的 DSH 长期记忆插件。

它不是“把聊天记录全塞进向量库”，而是模拟一个人怎么记、怎么忘、怎么突然想起来：

- 事实 / 偏好 / 事件 / 约定 / 教训分层；
- 重要度、情绪权重与时间衰减；
- 超出上限的旧记忆自动归档，不物理删除；
- 每轮按预算注入，不无脑塞满上下文；
- 轻量 PAD 心情与时间段状态，可关闭；
- 记忆可删除、可恢复；
- 每日把待整理聊天沉淀为长期记忆；
- 数据只在本机，不上传。

## 能力

| 能力 | 说明 |
|---|---|
| 记忆写入 | `remember` 动作，或每日沉淀 |
| 记忆检索 | 词法评分 + 时间/权重，无需外部向量服务 |
| 自动召回 | `before-context` 注入长期记忆 |
| 自动沉淀 | `after-response` 收进待整理队列，每日模型提炼 |
| 删除/恢复 | 软删除、恢复，均不物理抹除原始记忆 |
| 本地存储 | 使用宿主 documents/storage，不依赖外部数据库服务 |
| 隐私 | 默认不上传；只有启用模型沉淀时会调用宿主当前模型 |

## 安装

```bash
dsh plugin --profile desktop add github:147247586/dsh-companion-memory
```

启用插件时需要授予：

- `storage`：保存待整理队列和设置；
- `documents`：保存长期记忆；
- `history_read`：读取当天聊天用于沉淀；
- `model_generate`：每日沉淀时提炼记忆；
- `schedule`：每日定时任务。

## 设置

- **每轮记忆注入上限**：默认 900 字符；
- **最多保留记忆条数**：默认 400，超出后最旧归档；
- **每日沉淀时间**：默认 23:50；
- **自动沉淀**：默认开启。

## 隐私

- 记忆只保存在 DSH 本机数据目录；
- 不包含任何示例聊天、人格、账号或密钥；
- 删除是软删除，可恢复；
- 不会自动上传到第三方；只有 `model_generate` 会使用宿主当前模型。

## 局限

- 当前版本没有向量召回和图关系，主打“陪伴记忆”而非通用知识库；
- 标准插件 API 不提供图片读取，图片记忆不在本插件范围；
- 自动沉淀依赖宿主模型，会产生额外 token 消耗；
- 1.0 之前接口可能调整。
